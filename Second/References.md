## 🔍 Kanji Structure & Dictionary Tools
- [KanjiVG Viewer](https://kanjivg.tagaini.net/viewer.html)  
  An interactive viewer for the **KanjiVG** project, which provides detailed stroke order diagrams and structural info on kanji characters.
- [Tagaini Jisho](https://www.tagaini.net/)  
  A free, open-source Japanese dictionary application with rich features for learners.
